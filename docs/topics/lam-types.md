# اللَّام — A Map of Its Kinds

The single letter **لَام** appears across the whole chart of [particles](huruf-mabani-maani.md). The first question is whether it changes the iʿrāb at all; the second is what it does.

---

## Non-Working Lāms (No Effect on Iʿrāb)

| Lām | Function | Example |
|---|---|---|
| **لَام الاِبتِدَاء** | Emphasis at the head of a sentence | **لَيُوسُفُ وَأَخُوهُ أَحَبُّ** (Yūsuf 8) |
| [**اللَّام المُزَحلَقَة**](lam-muzaalaqa.md) | Emphasis, pushed along by **إِنَّ** | **إِنِّي لَيَحْزُنُنِي** (Yūsuf 13) |
| [**لَام الفَارِقَة**](lam-al-fariqah.md) | Marks **إِنْ** as emphatic, not negating | **وَإِن كُنتَ مِن قَبْلِهِ لَمِنَ الْغَافِلِينَ** (Yūsuf 3) |
| [**اللَّام المُوَطِّئَة لِلقَسَم**](lain-combination.md) | Paves the way for an unspoken oath | **لَئِنْ أَكَلَهُ الذِّئْبُ** (Yūsuf 14) |
| **لَام الجَوَاب** | On the reply of an [oath](jawab-al-qasam.md), or of [لَو](law-particle.md) / [لَوْلَا](lola.md) | **وَاللَّهِ لَأُحِبُّكَ**; **لَقَدْ كَانَ** (Yūsuf 7) |
| [**لَام البُعْد**](demonstrative-pronouns.md) | Marks distance in a demonstrative | **ذَٰلِكَ** vs **ذَاكَ** |

!!! important "Grammatical Effect, Not Effect on Meaning"
    These lāms change no ending, but they do change the meaning: an emphatic lām adds emphasis.

## Working Lāms

| Lām | Effect | Notes |
|---|---|---|
| [**لَام الجَار**](lam-al-jar-meanings.md) | The noun is majrūr | Over **30 meanings**, including [تَقْوِيَة](lam-taqwiyah.md), مِلك, and شِبه المِلك |
| [**لَام الأَمْر**](lam-al-amr.md) | The muḍāriʿ is majzūm | **لِيَكْتُبْ** — *he should write* |
| [**لَام الجُحُود**](lam-juhud.md), **لَام التَّعلِيل** | Listed by some as giving naṣb | Disputed: a hidden **أَنْ** does the naṣb |

!!! tip "Practice"
    Find examples of each kind of lām whenever you are reading the Quran.
